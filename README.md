# n8n-nodes-getmyopinion

[GetMyOpinion](https://www.getmyopinion.eu) nodes for n8n — send customer
satisfaction surveys for completed services.

Implements the **Send Survey** action of the GetMyOpinion survey API: one
node, one credential (Public Key + Secret), HMAC-signed requests.

## Prerequisites

- An n8n instance (self-hosted, or n8n Cloud once this package is a
  verified community node)
- A GetMyOpinion account with surveys enabled, and an API key pair
  (Public Key + Secret) generated by the account owner in GetMyOpinion

## Installation

Self-hosted (any recent n8n):

- Settings → Community nodes → Install → `n8n-nodes-getmyopinion`
- or, from your n8n server:
  `npm install n8n-nodes-getmyopinion` inside the n8n installation

n8n Cloud: available from the nodes panel once verified.

## Usage

1. Create a **GetMyOpinion API** credential with your Public Key and
   Secret, then use **Test connection** — it performs a signed request
   against `GET /me` and shows your business name on success.
2. Add the **GetMyOpinion** node to a workflow, choose **Send Survey**,
   and map the customer fields:
   - **First Name / Last Name** — customer name
   - **Email** and/or **Phone** — at least one contact is required
     (phone in international E.164 format, e.g. `+33612345678`)
   - **Service Code** — the activity key configured for your centre in
     GetMyOpinion
   - **Service Date** — actual completed service time, ISO 8601 with
     offset (e.g. `2026-11-02T10:00:00+01:00`); future dates are rejected
   - **External Event ID** — stable ID of the service event, prefixed by
     its source (e.g. `crm:appointment-0001`). Reuse the SAME ID across
     retries and re-runs: the API is idempotent on it, which makes
     re-running failed executions safe.

### Base URL

Requests go to `https://www.getmyopinion.eu` by default. Self-hosted
operators can override the origin with the `GMO_API_BASE_URL` environment
variable on the n8n instance (e.g. to point at a dedicated environment).
The base URL is never a credential field.

### Errors and retries

Failures surface actionable messages from the API (field-level validation
details, service-code hints, quota state). Transient failures tell you
that re-running the node is safe (same External Event ID = no duplicate).
Enable n8n's **Retry On Fail** on the node for automatic retries.

## Compatibility

- The published package has no runtime dependencies — the n8n host provides
  `n8n-workflow`. Node.js >= 20 on the n8n host.
- **Developing** this package needs Node.js >= 24: the `n8n-workflow`
  devDependency transitively compiles `isolated-vm`, which requires it.
